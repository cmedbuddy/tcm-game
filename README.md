# tcm-game
# 📜 懸壺濟世：百萬問答 | TCM Millionaire Quiz

An 8-bit Pixel Art Traditional Chinese Medicine (TCM) Quiz Game inspired by "Who Wants to Be a Millionaire?".

一款結合復古 8-bit 像素風格與《百萬富翁》玩法的「中醫基礎與養生問答網頁遊戲」。

Created by **[@cmedbuddy](https://www.instagram.com/cmedbuddy)**

## 🌟 Key Features / 特色
- 🌐 **Bilingual Support (雙語支援):** Toggle between Traditional Chinese & English seamlessly.
- 📜 **5 Difficulty Levels (5 大階梯關卡):** From daily wellness to professional TCM classics & prescriptions.
- ☯️ **Classic Lifelines (三大經典錦囊):** 50:50, Ask the Audience, Carrier Pigeon to Master.
- 🕊️ **Viral Sharing (飛鴿傳書):** One-click result clipboard copy for social media sharing.
